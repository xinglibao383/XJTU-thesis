\xchapter{相关理论与技术}{Related Theories and Techniques}

本章介绍本文研究所涉及的相关理论与关键技术，为后续方法设计提供必要的理论基础。首先介绍惯性测量单元（IMU）与WiFi信道状态信息（CSI）两类传感器的基本感知原理。随后介绍Transformer与Mamba两种深度学习时序建模网络结构，并分析其在长时序数据建模中的特点与适用场景。在此基础上，进一步介绍多模态特征对齐与融合方法，包括对比学习与交叉注意力机制，为后续多模态人体活动识别模型的设计提供理论依据。最后介绍自回归生成机制的基本思想，为人体姿态重构与预测方法的实现奠定基础。

\xsection{传感器}{Figures}

\xsubsection{惯性测量单元}{Single Figure}

惯性测量单元（Inertial Measurement Unit, IMU）是构建非视觉人体感知系统的核心接触式传感器，通常由三轴微机电系统（MEMS）加速度计和三轴陀螺仪正交构成。从物理观测范式来看，IMU遵循拉格朗日视角（Lagrangian Viewpoint），即传感器固连于人体肢体（载体），随肢体运动并实时记录其相对于惯性空间的动力学状态。这种“本体感知”特性使得IMU能够以高频采样率（通常高于50Hz）捕捉人体运动的微观纹理与瞬态变化。

在动力学测量方面，加速度计的物理本质是比力（Specific Force）传感器，而非纯粹的运动加速度传感器。根据牛顿第二定律，内部检测质量块受到的惯性力与支撑力平衡。加速度计输出的观测向量 $a_t$ 是载体坐标系（Body Frame, $b$）下的比力，其数学模型可表述为：
\begin{equation}
a_t = C_n^b (a_n - g_n) + b_a + n_a
\label{eq:acc_model}
\end{equation}
其中，$C_n^b$ 表示从导航坐标系（Navigation Frame, $n$，通常指世界坐标系）到载体坐标系的旋转矩阵，$a_n$ 为人体肢体在世界坐标系下的真实线性运动加速度，$g_n$ 为重力加速度向量（通常取 $[0, 0, -9.8] m/s^2$）。$b_a$ 和 $n_a$ 分别代表加速度计的零偏（Bias）和高斯白噪声。该公式表明，IMU采集的原始加速度数据是肢体运动分量与重力分量的非线性耦合。

与加速度计互补，陀螺仪基于科里奥利效应（Coriolis Effect）测量载体相对于惯性空间的旋转角速度。设 $\omega_t$ 为陀螺仪在时刻 $t$ 的输出向量，其测量模型为：
\begin{equation}
\omega_t = \omega_{true} + b_g + n_g
\label{eq:gyro_model}
\end{equation}
其中，$\omega_{true}$ 为真实的角速度矢量，$b_g$ 为陀螺仪固有的零偏不稳定误差，$n_g$ 为测量噪声。人体姿态的更新通常通过对角速度进行时间积分实现。在四元数（Quaternion）表征下，若当前姿态四元数为 $q_t$，其微分演化方程满足：
\begin{equation}
\dot{q}_t = \frac{1}{2} q_t \otimes \Omega(\omega_t)
\label{eq:quat_derivative}
\end{equation}
其中，$\otimes$ 表示四元数乘法，$\Omega(\omega_t)$ 为由角速度向量构成的反对称矩阵。这一运动学方程构成了基于惯性数据推演人体姿态的数学基础。

\xsubsection{WiFi信道状态信息}{Use subcaption instead of subfigure}

WiFi感知技术基于欧拉视角（Eulerian Viewpoint）监测固定空间区域内电磁场的波动，通过分析无线信号与目标的交互特征来反演运动状态。其物理基础在于正交频分复用（OFDM）技术，该技术将高速数据流调制到多个正交的子载波上并行传输，从而有效对抗频率选择性衰落。信道状态信息（Channel State Information, CSI）是物理层（PHY Layer）对无线信号在发射端（Tx）与接收端（Rx）之间传播特性的细粒度刻画，反映了信道频率响应（Channel Frequency Response, CFR）。

相较于接收信号强度（RSSI）仅提供单一的功率值，CSI以复数矩阵的形式记录了每一个子载波上的幅度和相位信息，能够描述信号在传播过程中受散射、反射及衍射影响后的微观变化。在频域上，对于第 $k$ 个子载波，接收信号 $Y_k$ 与发送信号 $X_k$ 之间的关系可由线性信道模型表示：
\begin{equation}
Y_k = H_k X_k + N_k
\label{eq:csi_model}
\end{equation}
其中，$N_k$ 为高斯白噪声，$H_k$ 为该子载波上的复数信道增益，即CSI。$H_k$ 可进一步分解为振幅 $|H_k|$ 与相位 $\angle H_k$：
\begin{equation}
H_k = |H_k| e^{j\angle H_k}
\label{eq:csi_phasor}
\end{equation}
振幅 $|H_k|$ 反映了信号在该频率分量上的能量衰减，主要受传播距离与障碍物遮挡影响；相位 $\angle H_k$ 则包含了信号传播的时间延迟信息，对距离变化具有极高的敏感度。

在室内环境中，无线信号并非沿单一路径传播，而是经过墙壁、地面、家具以及人体反射后形成多径叠加。当人体在WiFi覆盖区域内运动时，会对特定的传播路径产生扰动，导致接收端的CSI特征发生动态演变。基于多径传播理论，时变信道频率响应 $H(f, t)$ 可建模为所有静态与动态路径信号的相干叠加：
\begin{equation}
H(f, t) = \sum_{p=1}^P \alpha_p(t) e^{-j2\pi f \tau_p(t)}
\label{eq:multipath_model}
\end{equation}
其中，$P$ 为路径总数，$\alpha_p(t)$ 和 $\tau_p(t)$ 分别代表第 $p$ 条路径在时刻 $t$ 的衰减系数与传播时延。该公式揭示了WiFi感知的物理本质：人体的运动改变了反射路径的长度 $\tau_p(t)$ 和能量 $\alpha_p(t)$，进而在接收端引起CSI幅度和相位的规律性波动。这种基于“场”的感知机制使得CSI信号对环境布局变化表现出极高的敏感性，其特征分布本质上是人体运动与环境多径效应的耦合结果。

\xsection{深度学习网络}{Tables}

\xsubsection{Transformer}{Transformer}

Transformer架构自提出以来，凭借其基于注意力机制的并行计算能力，彻底改变了序列建模的范式。与循环神经网络（RNN）依赖递归更新隐藏状态不同，Transformer完全摒弃了递归结构，利用自注意力机制（Self-Attention Mechanism）直接建立序列中任意两个位置之间的依赖关系。对于人体姿态重构任务而言，这种全局感受野（Global Receptive Field）至关重要，因为它允许模型捕捉跨时间步的运动模式以及跨关节的空间几何约束。

Transformer的核心组件是缩放点积注意力（Scaled Dot-Product Attention）。给定输入序列的特征嵌入，模型将其分别映射为查询向量（Query, $Q$）、键向量（Key, $K$）和值向量（Value, $V$）。注意力权重的计算本质上是查询向量与键向量之间的相似度度量。数学上，对于维度为 $d_k$ 的输入，其注意力输出矩阵计算如下：
\begin{equation}
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
\label{eq:scaled_attention}
\end{equation}
其中，$\sqrt{d_k}$ 为缩放因子，用于防止点积结果过大导致Softmax函数进入梯度极小的饱和区。该公式表明，输出向量是所有值向量 $V$ 的加权和，而权重取决于 $Q$ 与对应 $K$ 的匹配程度。在人体感知场景中，这意味着某一时刻的姿态特征更新可以参考序列中所有历史时刻的信息，从而有效解决RNN在长序列下的遗忘问题。

为了增强模型对不同子空间特征的捕捉能力，Transformer引入了多头注意力机制（Multi-Head Attention）。通过将 $Q$、$K$、$V$ 线性投影到 $h$ 个不同的子空间中并行计算注意力，最后将结果拼接并进行线性变换：
\begin{equation}
\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, ..., \text{head}_h)W^O
\label{eq:multihead}
\end{equation}
\begin{equation}
\text{where } \text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)
\label{eq:attention_head}
\end{equation}
这种机制使得模型能够从不同的表示子空间中学习人体运动的多样性特征，例如一个注意力头关注肢体的周期性摆动，另一个头关注突发的冲击信号。

此外，由于自注意力机制本身具有排列不变性（Permutation Invariant），无法感知序列的时序顺序。Transformer通过引入位置编码（Positional Encoding）来注入位置信息。通常采用正弦和余弦函数生成位置向量 $PE$：
\begin{equation}
PE_{(pos, 2i)} = \sin(pos / 10000^{2i/d_{model}})
\label{eq:pe_sin}
\end{equation}
\begin{equation}
PE_{(pos, 2i+1)} = \cos(pos / 10000^{2i/d_{model}})
\label{eq:pe_cos}
\end{equation}
这种编码方式使得模型能够感知绝对位置以及相对位置距离，确保了时间序列数据的时序严谨性。综上所述，Transformer通过全量的注意力计算，为处理具有复杂空间相关性和长时依赖的人体运动序列提供了强大的理论支撑，尤其适用于对几何精度要求极高的姿态重构任务。

\xsubsection{Mamba}{Mamba}

尽管Transformer架构在全局依赖建模上表现卓越，但其自注意力机制的计算复杂度随序列长度呈二次方增长，这在处理高采样率传感器生成的长时序数据时带来了巨大的计算负担与内存瓶颈。为了在建模能力与计算效率之间寻求最优平衡，本研究引入了选择性状态空间模型（Selective State Space Models, SSM），即Mamba架构。Mamba结合了循环神经网络（RNN）的推理高效性与卷积神经网络（CNN）的并行训练优势，能够以线性时间复杂度高效处理长序列数据。

Mamba的数学基础源于经典控制理论中的线性时不变（LTI）系统，其核心是将一维输入序列 $x(t)$ 通过隐状态 $h(t)$ 映射为输出序列 $y(t)$。在连续时间域内，该过程由一阶常微分方程描述：
\begin{equation}
h'(t) = A h(t) + B x(t)
\label{eq:ssm_state}
\end{equation}
\begin{equation}
y(t) = C h(t)
\label{eq:ssm_output}
\end{equation}
其中，$A \in \mathbb{R}^{N \times N}$ 为状态演化矩阵，决定了系统的动态特性；$B \in \mathbb{R}^{N \times 1}$ 和 $C \in \mathbb{R}^{1 \times N}$ 分别为输入投影矩阵与输出投影矩阵。该方程刻画了系统状态随时间的演化规律，为长序列数据的压缩与记忆提供了数学形式。然而，由于传感器采集的数据本质上是离散采样信号，必须通过零阶保持（Zero-Order Hold, ZOH）技术将上述连续系统离散化。引入时间尺度参数 $\Delta$，将连续参数 $(A, B)$ 转换为离散参数 $(\bar{A}, \bar{B})$，离散化后的状态转移方程演变为：
\begin{equation}
h_t = \bar{A} h_{t-1} + \bar{B} x_t
\label{eq:discrete_state}
\end{equation}
\begin{equation}
y_t = C h_t
\label{eq:discrete_output}
\end{equation}
其转换关系满足 $\bar{A} = \exp(\Delta A)$ 与 $\bar{B} = (\Delta A)^{-1}(\exp(\Delta A) - I) \cdot \Delta B$。这种递归形式使得模型在推理阶段可以像RNN一样运作，仅需维护当前的隐状态 $h_t$ 即可处理下一时刻的输入，从而将推理时的显存占用与计算复杂度显著降低至 $O(1)$（对于单步推理）或 $O(L)$（对于序列长度 $L$）。

传统的SSM模型受限于参数 $(A, B, C)$ 的线性时不变性，难以根据上下文动态调整关注点。为了突破这一瓶颈，Mamba引入了“选择性机制”（Selection Mechanism），将参数 $B$、$C$ 和 $\Delta$ 参数化为输入 $x_t$ 的函数：
\begin{equation}
B_t = S_B(x_t), \quad C_t = S_C(x_t), \quad \Delta_t = \text{Softplus}(\text{Parameter} + S_\Delta(x_t))
\label{eq:selective_param}
\end{equation}
这种输入依赖性（Input-Dependent）赋予了模型“内容感知”的能力，使其能够根据当前的信号特征动态调节信息流的遗忘与记忆。例如，在人体活动识别中，当输入为无意义的环境噪声时，模型可以通过调整 $\Delta_t$ 使得状态不更新以过滤干扰；当检测到关键动作波形时，则快速更新隐状态以捕捉特征。结合硬件感知的并行扫描算法（Parallel Associative Scan），Mamba能够在GPU上高效计算非线性状态空间，从而在保证线性计算复杂度的前提下，实现了对长时序传感器数据的高效特征提取与时序建模，为解决HAR任务中的实时性与长程依赖问题提供了理想的数学工具。

\xsection{多模态特征融合与对齐}{Figures}

在人体感知任务中，异构传感器模态的有效融合是提升系统鲁棒性与精确度的关键。与单一模态相比，多模态数据能够从动力学特征与环境电磁特征两个维度提供互补信息。然而，如何打破不同物理属性、不同采样频率数据之间的“模态鸿沟”，并建立深层的语义关联，是本研究面临的核心挑战。本节将深入探讨交叉注意力机制、对比学习架构以及自回归时序建模的理论基础，为后续章节中异构数据的深度对齐与姿态预测提供理论依据。

\xsubsection{对比学习}{Constrictive Learning}

在多模态人体活动识别任务中，惯性测量单元（IMU）记录的动力学特征与WiFi记录的空间场特征在物理属性、数据分布及维度上存在本质差异，形成了严峻的模态鸿沟。传统的融合方法往往假设异构特征在原始空间或浅层映射后即可线性叠加，忽略了特征分布的不一致性，容易导致多模态信息的相互干扰而非互补。为了解决这一问题，本研究引入跨模态对比学习（Cross-Modal Contrastive Learning）作为表征对齐的关键机制。其核心思想并非直接对异构数据进行分类，而是通过在潜在语义空间中度量样本间的相似性，强制语义相关的配对样本（正样本）相互靠近，而语义无关的非配对样本（负样本）相互远离，从而构建一个共享的、具备语义一致性的高维流形。

受大规模图文预训练模型CLIP的启发，本研究摒弃了传统对比学习中繁琐的二元组或三元组正负样本挖掘过程，转而采用基于批次（Batch-wise）的全局相似度计算范式。假设在一个训练批次中包含 $N$ 个时间同步的传感器数据片段对 $\{(x_i^{I}, x_i^{W})\}_{i=1}^N$，其中 $x_i^{I}$ 和 $x_i^{W}$ 分别代表第 $i$ 个样本的IMU数据与WiFi数据。首先，通过各自的特征提取网络将原始数据映射为高维特征向量，并经过非线性投影头映射至同一维度的度量空间，得到归一化的嵌入向量 $u_i$ 和 $v_i$。在此基础上，算法构建一个 $N \times N$ 的全量相似度矩阵 $S$，其中第 $i$ 行第 $j$ 列的元素 $S_{ij}$ 表示IMU样本 $i$ 与WiFi样本 $j$ 之间的余弦相似度：
\begin{equation}
S_{ij} = \frac{f_{IMU}(x_i^{I}) \cdot f_{WiFi}(x_j^{W})}{\|f_{IMU}(x_i^{I})\| \|f_{WiFi}(x_j^{W})\|} = u_i^T v_j
\label{eq:similarity_matrix}
\end{equation}
在该相似度矩阵中，对角线元素 $S_{ii}$ 对应于时间同步的真实配对样本（即同一时刻的人体动作），应被最大化；而非对角线元素 $S_{ij} (i \neq j)$ 对应于批次内其他时刻或不同动作的样本组合，属于负样本，应被最小化。这一优化目标等价于在批次内进行 $N$ 类分类问题。为了同时利用IMU到WiFi和WiFi到IMU的双向信息，本研究采用对称的对比损失函数。具体而言，对于每一个IMU样本 $i$，将其视为“查询”，计算其与批次内所有WiFi样本的匹配概率，构建IMU-to-WiFi的损失 $L_i^{I \rightarrow W}$：
\begin{equation}
L_i^{I \rightarrow W} = -\log \frac{\exp(S_{ii} / \tau)}{\sum_{k=1}^N \exp(S_{ik} / \tau)}
\label{eq:loss_i2w}
\end{equation}
同理，计算WiFi-to-IMU的损失 $L_i^{W \rightarrow I}$：
\begin{equation}
L_i^{W \rightarrow I} = -\log \frac{\exp(S_{ii} / \tau)}{\sum_{k=1}^N \exp(S_{ki} / \tau)}
\label{eq:loss_w2i}
\end{equation}
其中，$\tau$ 为可学习的温度系数，用于调节Softmax分布的平滑程度，控制模型对困难负样本的挖掘力度。最终的总损失函数为两者的平均值：
\begin{equation}
L_{CL} = \frac{1}{2N} \sum_{i=1}^N (L_i^{I \rightarrow W} + L_i^{W \rightarrow I})
\label{eq:total_cl_loss}
\end{equation}
通过最小化该损失函数，模型在反向传播过程中能够实现两个关键特性：一是“对齐性”（Alignment），即拉近同一动作在异构模态下的特征距离，消除物理属性差异带来的隔阂；二是“均匀性”（Uniformity），即迫使特征向量在超球面上尽可能均匀分布，保留更多的语义信息并防止模式崩塌。这种基于CLIP范式的对比学习策略，为后续的多任务分类网络提供了鲁棒且对齐的特征底座，是解决异构感知数据深度融合的数学基础。

\xsubsection{交叉注意力机制}{Cross-Attention Mechanism}

尽管跨模态对比学习能够将异构数据映射至统一的语义流形，实现了全局特征的对齐，但它并未解决模态间细粒度特征的交互与融合问题。在多模态人体活动识别中，惯性数据与射频数据虽然描述同一动作，但其关注点截然不同：IMU聚焦于肢体的微观动力学变化，而WiFi聚焦于宏观的空间环境扰动。为了有效地融合这两种包含不同语义层级且在时序上可能存在非线性延迟的信息，本研究引入交叉注意力机制（Cross-Attention Mechanism）。与自注意力机制不同，交叉注意力的核心在于其查询向量（Query）与键值对向量（Key-Value）来源于不同的模态，这使得模型能够动态地利用一个模态的信息去通过注意力权重“检索”并聚合另一个模态中的互补特征。

假设经过特征提取后的IMU特征序列为 $X_A \in \mathbb{R}^{L_A \times d}$，WiFi特征序列为 $X_B \in \mathbb{R}^{L_B \times d}$。以IMU特征为主模态去融合WiFi特征为例，首先通过线性投影生成查询、键和值矩阵。此时，查询矩阵 $Q_A$ 源自IMU特征，而键矩阵 $K_B$ 和值矩阵 $V_B$ 则源自WiFi特征：
\begin{equation}
Q_A = X_A W^Q, \quad K_B = X_B W^K, \quad V_B = X_B W^V
\label{eq:cross_projection}
\end{equation}
其中，$W^Q, W^K, W^V \in \mathbb{R}^{d \times d_k}$ 为可学习的线性投影权重。交叉注意力的计算过程旨在衡量IMU序列中第 $i$ 个时间步的特征与WiFi序列中所有时间步特征的相关性。注意力权重矩阵及最终的融合输出 $O_{A \leftarrow B}$ 计算如下：
\begin{equation}
O_{A \leftarrow B} = \text{softmax}\left(\frac{Q_A K_B^T}{\sqrt{d_k}}\right) V_B
\label{eq:cross_attention_calc}
\end{equation}
在该公式中，点积项 $Q_A K_B^T$ 构建了一个跨模态的相似度图（Affinity Map）。对于IMU中的每一个动作片段，该机制会自动寻找WiFi信号中与之最相关的空间特征片段，并赋予其更高的权重。随后，通过对值矩阵 $V_B$ 的加权求和，将相关的WiFi环境信息注入到IMU的动力学特征中。

这种交互机制在物理层面上具有明确的解释性：它允许模型在处理IMU的加速度突变时，参考同期的WiFi多径变化情况，从而判断该突变是由人体运动引起还是环境噪声导致。为了实现双向的信息互补，通常会并行构建 $O_{A \leftarrow B}$ 与 $O_{B \leftarrow A}$ 两个方向的交叉注意力流，通过多头（Multi-Head）并行计算捕获不同子空间下的模态关联。最终，交叉注意力机制有效地解决了异构数据在时空维度上的局部错位问题，为后续的多任务分类提供了富含多模态上下文的增强表征。

\xsection{自回归生成机制}{Autoregressive Mechanism}

传统的人体姿态估计方法大多采用判别式（Discriminative）范式，即将姿态重构视为一个从传感器输入空间到关节坐标空间的静态映射问题。在这种框架下，模型仅关注如何最大化后验概率 $P(Y_t | X_t)$，即给定当前时刻的传感器观测 $X_t$，求解当前时刻的最优姿态 $Y_t$。然而，这种单向映射忽略了人体运动在时间维度上的连续性与因果依赖，导致模型本质上是一个静态的“估计器”而非动态的“预测器”。当面临需要预判动作趋势的场景时，此类方法无法利用历史运动规律进行有效推演，这正是现有研究缺乏动态预测能力的症结所在。为了突破这一局限，本研究引入自回归（Autoregressive, AR）生成机制，将人体姿态重构建模为基于时序历史的序列生成问题。

自回归生成模型的核心假设是：序列数据中某一时刻的状态严格依赖于其先前时刻的历史状态。对于人体运动序列 $S = \{s_1, s_2, ..., s_T\}$（其中 $s_t$ 可代表时刻 $t$ 的姿态向量或虚拟传感器数据），其联合概率分布 $P(S)$ 根据概率链式法则可分解为一系列条件概率的乘积：
\begin{equation}
P(S) = \prod_{t=1}^{T} P(s_t | s_1, s_2, ..., s_{t-1}) = \prod_{t=1}^{T} P(s_t | s_{<t})
\label{eq:ar_probability}
\end{equation}
该公式揭示了自回归机制的数学本质：当前时刻的输出不仅仅是当前输入的函数，更是整个历史轨迹的函数。在深度学习框架下，我们通常使用参数化神经网络（如前文所述的Causal Transformer）来拟合上述条件概率分布。这就要求模型在结构上必须遵循“因果约束”（Causal Constraint），即在计算时刻 $t$ 的特征时，严禁泄露时刻 $t$ 之后的未来信息。这通常通过在注意力机制中引入因果掩码（Causal Mask）来实现，确保感受野严格限制在历史时间窗内。

在推理阶段，自回归模型采用递归生成（Recursive Generation）的策略。不同于训练阶段可以使用真实标签进行并行计算（即Teacher Forcing模式），推理时模型需要将上一时刻生成的预测值 $\hat{s}_{t-1}$ 重新反馈至输入端，作为推演时刻 $t$ 的上下文依据。这种反馈回路（Feedback Loop）使得模型能够捕捉人体运动的内在动力学规律（Intrinsic Dynamics）。例如，在步态周期中，下肢的摆动具有高度的可预测性，模型可以通过学习历史时刻的角速度趋势，利用自回归机制在缺乏当前观测的情况下，“惯性”地推演出下一时刻的肢体位置。

具体到本研究的姿态重构任务中，自回归机制被用于构建IMU数据的预测闭环。模型不仅学习从IMU到姿态的映射，还同步学习IMU信号本身的时序演化规律：
\begin{equation}
\hat{x}_{t+1} = f_\theta(x_1, x_2, ..., x_t)
\label{eq:ar_prediction}
\end{equation}
其中 $f_\theta$ 为神经网络模型。通过不断将预测生成的虚拟IMU数据 $\hat{x}_{t+1}$ 注入输入流，系统能够利用历史信息构建未来的运动流形。这种生成式范式将姿态重构任务的定义从单纯的“状态恢复”拓展为“趋势预测”，从根本上解决了现有方法仅能感知当下而缺乏动态预测能力这一核心缺陷。

本章系统梳理了本文研究任务所涉及的核心理论与技术，为后续的方法设计与实验分析奠定了基础。内容首先涵盖了两类关键传感器：惯性测量单元与WiFi信道状态信息，明确了异构数据的物理感知特性；其次，探讨了Transformer与Mamba深度学习骨干网络，分析了其在长序列建模中的适用场景。在此基础上，重点阐述了多模态特征融合与对齐的关键技术，包括跨模态对比学习与交叉注意力机制，并介绍了用于实现动态时序推演的自回归生成理论。上述理论体系共同构成了解决异构数据深度融合及人体姿态动态预测问题的技术路径。
