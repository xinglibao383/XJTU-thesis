\xsection{结论}{Abstracts}

本文针对普适计算环境下人体感知技术在跨模态对齐、长时序依赖建模以及未来动态预测等方面面临的挑战，系统地研究了基于 IMU 和 WiFi 信号的人体活动识别与姿态重构方法。通过理论推导、模型构建与多维度的实验验证，本文在异构数据融合机制、任务驱动的架构选型以及生成式姿态推演等方面取得了如下研究成果：

首先，本文提出并实现了基于多模态语义对齐的协同识别框架 WICTIVITY。针对 IMU 与 WiFi 信号存在的物理特质差异，本文构建了基于 Mamba 架构的双分支特征提取网络，利用其线性计算复杂度实现了对长序列感知数据的高效建模。通过引入对比学习（Contrastive Learning）训练策略，本文成功地在特征空间中强制实现了异构模态的语义对齐，有效滤除了环境噪声并增强了动作特征的判别力。实验结果表明，该模型在多任务联合识别中表现卓越，活动识别准确率达到 96.06\%，身份识别与场景识别准确率分别达到 99.93\% 和 99.99\%。这不仅验证了对比学习对跨模态感知能力的显著增强作用，也证明了 Mamba 架构在处理大规模语义分类任务时的优越性。

其次，本文设计并开发了基于自回归机制的人体姿态重构与预测模型 AIPose。该模型打破了传统姿态估计方法的静态限制，通过构建闭环的自回归架构，实现了对当前姿态的高精度重构及对未来动作的超前预测。在架构选型上，本文通过深入的对比研究发现，对于空间几何精度敏感的回归任务，具备全局特征关联能力的 Transformer 架构在保真度上显著优于高度压缩的隐状态模型。在 XRFV2 数据集上的验证结果显示，AIPose 模型实现了厘米级的精度控制，关节重构误差仅为 49.34 毫米，预测误差为 55.19 毫米。这一成果不仅为元宇宙、时延补偿等实时交互场景提供了技术支撑，更揭示了深度学习架构在不同性质感知任务中的性能边界。

综上所述，本文的两项研究工作形成了一个从“语义理解”到“几何推演”的完整感知体系。通过对对比学习机制与不同时序建模主干（Mamba 与 Transformer）的深入探索，本文不仅提升了多模态人体感知的精度与鲁棒性，更在任务驱动的架构优化方面提供了具有参考价值的学术见解。

\xsection{展望}{Abstracts}

尽管本文在基于多模态融合的人体活动识别与自回归姿态重构预测方面取得了一定的研究成果，验证了相关模型在闭集环境与短时预测任务中的有效性，但面向更加开放、复杂的普适计算应用场景，现有工作仍存在一定的局限性，未来研究可从以下几个维度展开深入探索。

首先，针对WICTIVITY模型在跨场景与跨用户测试中出现的性能衰减问题，未来的工作将重点攻克跨域泛化这一技术难点。本文实验表明，WiFi CSI信号虽然富含环境与生物特征，但其对空间布局与个体体型的高度敏感性导致了严重的域偏移现象。未来的研究可以引入无监督域自适应（Unsupervised Domain Adaptation, UDA）或对抗性迁移学习机制，通过在特征提取层施加最大化域混淆的约束，迫使模型学习剥离了环境背景噪声的“纯净”活动特征。此外，考虑到新用户注册的实际需求，探索基于元学习（Meta-learning）或少样本学习（Few-shot Learning）的快速适配策略也是一个重要的方向，旨在利用极少量的校准数据即可能够让模型迅速适应新的物理环境或用户个体，从而提升系统在开放世界中的可用性。

其次，针对AIPose模型在长时序自回归预测中不可避免的误差累积问题，未来的研究将致力于引入多模态约束与概率生成机制来缓解这一漂移现象。目前的自回归框架主要依赖IMU数据的内部一致性，缺乏外部绝对参考系，导致随着预测时间步长的增加，生成的姿态容易逐渐偏离真实物理空间。未来可以考虑引入视觉模态（如单目摄像头）或环境地图信息作为辅助校正信号，构建“视觉-惯性”紧耦合的预测系统，利用视觉提供的绝对位置信息周期性地重置惯性积分误差。同时，为了应对长时预测中的不确定性，可以将现有的确定性回归模型扩展为基于扩散模型（Diffusion Models）或变分自编码器（VAE）的概率生成模型。通过对人体运动流形的概率分布进行建模，模型不再输出单一的确定性轨迹，而是生成符合生物力学约束的多种潜在运动假设，从而在物理合理性与多样性之间取得更好的平衡，从根本上抑制长时预测中的“崩塌”或“发散”现象。
