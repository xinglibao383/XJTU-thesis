\xsection{结论}{Abstracts}

本文围绕基于非视觉传感器的人体行为感知问题开展研究，主要针对多模态人体活动识别中异构特征难以有效对齐、跨受试者场景下模型泛化能力不足，以及基于 IMU 的人体姿态重构方法缺乏未来运动建模能力等问题，分别从人体活动识别和人体姿态重构与预测两个方面进行了研究。

在人体活动识别方面，本文提出了多模态融合方法 WICTIVITY。该方法分别对 IMU 与 WiFi CSI 时序数据进行特征提取，通过跨模态对比学习将两种模态映射到统一语义空间，并利用交叉注意力机制实现模态间的信息交互与融合。在此基础上，结合多任务学习策略，对活动类别、身份信息和场景信息进行联合建模，以增强融合特征的判别能力。实验结果表明，所提出方法在 XRFV2 数据集上的活动识别准确率达到 96.06\%，说明 IMU 与 WiFi 两种模态在人体活动感知中具有较好的互补性，所设计的特征对齐与融合方法能够有效提升识别性能。针对跨受试者场景下模型性能下降的问题，本文进一步设计了基于类别原型的少样本适配策略。该策略利用源域类别原型对目标用户特征进行约束，并结合轻量化适配模块完成少样本条件下的快速微调。实验结果表明，模型在未见受试者上的平均活动识别准确率为 72.08\%，在仅使用少量目标用户数据进行微调后，准确率可进一步提升至 87.29\%。该结果说明，所提出方法能够在较低标注成本条件下缓解不同受试者之间的分布差异，提升模型在实际应用场景中的适应能力。

在人体姿态重构与预测方面，本文提出了基于自回归机制的 AIPose 方法。该方法仅使用 IMU 数据作为输入，通过 IMU 特征提取模块、姿态重构模块和 IMU 预测模块构建闭环建模框架，在恢复当前时间段姿态信息的同时，对未来 IMU 信号及未来姿态进行递归预测。实验结果表明，AIPose 在 XRFV2 数据集上的当前姿态重构 MPJPE 为 49.35，未来姿态预测 MPJPE 为 55.19，说明该方法能够在保持较好重构效果的基础上实现短时预测。

综合来看，本文围绕人体活动识别和人体姿态重构与预测两个任务，分别从多模态特征对齐与融合、跨受试者少样本适配以及人体运动时序建模三个方面进行了研究。相关结果表明，基于 IMU 和 WiFi 的非视觉感知方法能够较好支持室内环境下的人体活动理解，而基于 IMU 的自回归建模方法也为姿态的连续重构与短时预测提供了可行思路。本文的研究为后续面向实际应用场景的非视觉人体感知研究提供了方法基础。

\xsection{展望}{Abstracts}

尽管本文取得了一定研究结果，但仍有一些问题值得进一步研究。

首先，本文提出的活动识别方法在受试者内测试中表现较好，但在跨受试者场景下仍然存在明显性能下降，说明模型对个体差异和环境变化仍较为敏感。后续可以进一步研究更稳定的跨域表征学习方法，例如结合自监督预训练、域泛化或无监督适配策略，减少模型对目标用户标注数据的依赖，并提升其在新用户和新场景下的直接泛化能力。

其次，本文的人体姿态任务已经能够实现较好的当前重构和短时预测，但随着预测时间增长，误差仍会逐步累积。后续可以从两个方面继续完善：一方面，引入更强的时序约束或人体运动学约束，提升长时间预测的稳定性；另一方面，探索更合理的姿态表示方式和更稳定的监督形式，以增强模型对复杂运动过程的表达能力。

最后，本文两个任务分别侧重多模态活动识别和基于 IMU 的姿态建模，尚未在统一框架下实现更深层的联合建模。后续可以探索将活动语义、环境信息与姿态变化过程进行协同建模，进一步挖掘不同任务之间的互补关系。同时，在系统层面还需要结合实际部署需求，对传感器数量、佩戴方式、实时性和长期使用稳定性进行更系统的评估，以提高方法在智慧康养、人机交互和居家监测等场景中的应用可行性。
