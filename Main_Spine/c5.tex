\xchapter{总结和展望}{Summary and Future Work}

\xsection{总结}{Summary}

本文围绕复杂室内环境下的非视觉人体感知问题展开研究，重点关注人体活动识别与人体姿态重构与预测两个任务。人体活动识别任务面向离散活动语义理解，旨在根据多模态非视觉信号判断人体活动类别；人体姿态重构与预测任务则进一步面向连续人体运动状态建模，旨在根据 IMU 时序信号恢复当前姿态并预测未来姿态变化。两部分工作在研究层次上由宏观活动语义识别延伸至细粒度姿态时序建模，在应用目标上共同服务于隐私友好、部署灵活且适用于复杂室内环境的人体感知需求。

在人体活动识别任务中，针对单一非视觉模态信息表达有限、IMU 与 WiFi CSI 异构模态特征分布差异明显以及跨受试者泛化能力不足等问题，本文提出了基于多模态对齐与融合的人体活动识别方法 WIHAR。该方法以同步采集的 IMU 与 WiFi CSI 数据为输入，首先通过两个参数独立的 Mamba 时序编码分支分别提取两种模态的高层时序特征；随后引入跨模态双向对比学习约束，在 IMU 到 WiFi CSI 和 WiFi CSI 到 IMU 两个方向上增强同一样本跨模态表示的一致性；在此基础上，通过交叉注意力机制建模模态间细粒度交互关系，进一步利用两种模态之间的互补信息。实验结果表明，在 XRFV2 数据集上，WIHAR 的活动识别准确率达到 95.81\%，宏平均 F1、宏平均精确率和宏平均召回率分别达到 95.29\%、95.48\% 和 95.13\%，均优于多种代表性基线方法；在 OctoNet 数据集上的补充验证结果也表明，WIHAR 在其他包含 WiFi 和 IMU 双模态数据集上仍保持较好的识别性能。围绕模型结构与训练策略开展的实验进一步表明，Mamba 时序编码骨干、跨模态双向对比学习、交叉注意力机制以及类别权重策略均对模型性能提升具有积极作用。此外，本文设计的基于类别原型的跨受试者适配策略能够在少量目标受试者标注样本条件下提升模型对未见个体的适应能力，使跨受试者设置下的平均识别准确率由 72.57\% 提升至 90.99\%。

在人体姿态重构与预测任务中，针对现有基于 IMU 的人体姿态方法多聚焦于当前姿态重构、对未来姿态预测关注不足的问题，本文提出了基于自回归建模机制的人体姿态重构与预测方法 AIPose。该方法以当前 IMU 序列为输入，构建由 IMU 时序特征提取模块、姿态重构模块、IMU 时序预测模块和自回归姿态预测机制组成的统一框架。一方面，模型利用当前 IMU 序列对应的时序特征完成当前姿态重构；另一方面，模型进一步预测未来 IMU 序列，并将预测得到的未来 IMU 序列与当前 IMU 序列尾部进行拼接，构造扩展 IMU 输入，从而实现未来姿态预测。实验结果表明，在 XRFV2 数据集上，AIPose 当前姿态重构的 MPJPE 为 52.20\,px，PCK@5px、PCK@10px 和 PCK@20px 分别达到 16.13\%、26.86\% 和 44.55\%；未来姿态预测的 MPJPE 为 57.36\,px，PCK@5px、PCK@10px 和 PCK@20px 分别达到 16.48\%、26.65\% 和 43.51\%。进一步地，DIP-IMU、AMASS 和 IMUPoser 数据集上的补充实验表明，AIPose 在不同 IMU 姿态数据上能够保持相对稳定的当前姿态建模能力，并进一步支持未来姿态预测任务。围绕 AIPose 的实验分析还表明，Transformer 时序预测骨干、合适的 IMU 输入窗口长度、输入标准化处理以及多设备信息融合均有助于提升姿态建模性能；长时预测与扰动鲁棒性实验则说明，AIPose 在自回归预测过程中虽存在误差传播现象，但整体误差演化相对平稳，未出现持续发散或崩溃行为。

总体来看，本文从人体活动识别与人体姿态重构与预测两个层面对非视觉人体感知问题进行了系统研究。第三章验证了 IMU 与 WiFi CSI 多模态对齐与融合对于提升人体活动识别性能的有效性，并通过跨受试者适配策略提高了模型在未见个体条件下的识别能力；第四章则将研究重点从离散活动语义识别扩展到连续人体姿态建模，验证了基于 IMU 时序信号同时实现当前姿态重构与未来姿态预测的可行性。两部分研究在任务层次上相互衔接，在技术路径上共同体现了非视觉传感信号在隐私敏感、光照受限或视觉方法不适用场景中的应用潜力，为复杂室内环境下人体感知系统的构建提供了可行思路。

\xsection{展望}{Future Work}

尽管本文围绕非视觉人体感知中的人体活动识别与人体姿态重构与预测任务开展了较为系统的研究，并在多项实验中验证了所提方法的有效性，但从实验结果和应用需求来看，仍存在若干值得进一步深入研究的问题。特别是在人体姿态重构与预测任务中，当前姿态重构精度、多任务优化平衡、跨场景与跨受试者泛化能力，以及长时预测稳定性和抗干扰能力仍有进一步提升空间。

首先，在人体姿态重构与预测任务中，当前姿态重构性能仍有进一步提升空间。本文提出的 AIPose 重点在于构建当前姿态重构与未来姿态预测的统一建模框架，因此模型训练同时受到当前姿态重构、未来 IMU 序列预测和未来姿态预测三个目标的约束。实验结果表明，该方法在 XRFV2 数据集上取得了较好的当前姿态重构性能，但在 DIP-IMU、AMASS 和 IMUPoser 等补充数据集上，与 ASIP、TIP 等专门面向当前姿态估计任务设计的方法相比，部分当前姿态重构指标仍存在差距。这说明在多任务联合建模框架下，如何在当前姿态重构精度与未来预测能力之间取得更优平衡，仍是后续需要重点研究的问题。未来可以从更强的 IMU 特征提取器、更精细的人体结构先验、更合理的姿态解码模块以及动态损失权重分配等方面进行改进。例如，可引入基于人体运动链约束的姿态解码结构，以增强模型对关节层级关系的表达能力；也可采用不确定性加权、梯度平衡或阶段式训练策略，对当前姿态重构、未来 IMU 预测和未来姿态预测三个目标进行更精细的权重调节，从而减少多任务目标之间的相互干扰，进一步提升当前姿态重构精度和整体建模性能。

其次，人体姿态重构与预测模型的泛化能力仍需进一步增强。第四章中的跨受试者与跨场景实验表明，当测试数据来自未参与训练的受试者或未见场景时，模型性能会出现明显下降。这说明当前模型对个体运动习惯、身体结构差异、设备佩戴方式变化以及环境分布变化仍较为敏感。尤其是在实际部署场景中，用户体型、动作幅度、佩戴位置和传感器噪声均可能与训练数据存在差异，若模型缺乏足够的泛化能力，将限制其在真实应用中的稳定性和可迁移性。未来研究可进一步探索面向 IMU 姿态建模的域泛化、少样本适配和测试时自适应方法。例如，可通过域不变特征学习减小不同受试者和不同场景之间的特征分布差异；可利用少量目标用户数据进行参数高效适配，以降低个体差异带来的性能下降；也可结合自监督预训练或跨数据集联合训练，提升模型对不同数据来源和不同传感器配置的适应能力。进一步地，在设备佩戴位置发生偏移或传感器数量发生变化时，如何保持模型稳定输出，也是后续面向实际部署需要重点考虑的问题。

最后，长时预测能力和抗干扰能力仍有待进一步提高。本文的长时预测与扰动鲁棒性实验表明，AIPose 在短时预测范围内能够保持相对稳定的性能，且在受到一定噪声扰动后未出现明显误差发散现象。然而，随着预测时间不断延长，模型误差仍会逐渐累积，说明当前自回归框架对长期运动演化规律的刻画仍不充分。在真实应用中，传感器噪声、丢包、佩戴松动以及人体运动突变等因素都可能进一步加剧误差传播，从而影响未来姿态预测的可靠性。未来研究可从长时序建模、多尺度预测和鲁棒性增强三个方面继续改进。一方面，可引入层次化时序建模结构或多尺度预测机制，使模型同时捕获短期局部动态和长期运动趋势；另一方面，可结合人体运动学约束、物理可行性约束或生成式预测模型，提高长时预测结果的稳定性和合理性。此外，还可以在训练阶段引入更系统的噪声增强、传感器缺失模拟和扰动一致性约束，使模型在面对真实传感器噪声和异常输入时具有更强的鲁棒性。

综上，未来工作可围绕当前姿态重构精度提升与多任务优化平衡、跨受试者和跨场景泛化能力增强、长时预测与抗干扰能力提升三个方向继续展开。通过进一步改进模型结构、优化训练策略并增强真实部署条件下的适应能力，有望推动非视觉人体感知方法向更高精度、更强泛化能力和更高实际可用性的方向发展。
