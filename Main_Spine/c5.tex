\xchapter{结论与展望}{Conclusions and Future Work}

\xsection{结论}{Conclusions}

本文围绕基于非视觉传感器的人体行为感知问题，针对多模态人体活动识别中的异构特征对齐与融合、跨受试者场景下的泛化能力，以及基于 IMU 的人体姿态重构与预测问题开展研究，主要结论如下。

首先，在人体活动识别任务中，本文提出了多模态融合方法 WIHAR。该方法分别对 IMU 与 WiFi CSI 时序数据进行特征建模，并通过跨模态对比学习将两种模态映射到统一语义空间，再利用交叉注意力机制实现模态间的特征交互与融合。在此基础上，结合基于类别原型的少样本适配策略，对跨受试者场景下的分布差异进行缓解。实验结果表明，WIHAR 在 XRFV2 数据集上的多模态活动识别准确率达到 96.06\%。在跨受试者实验中，模型初始识别准确率为 72.57\%，经少量目标受试者数据微调后可提升至 90.99\%。这说明所提出方法能够较好利用 IMU 与 WiFi 的互补信息，并在一定程度上提升模型在新受试者上的适应能力。

其次，在人体姿态重构与预测任务中，本文提出了基于自回归机制的方法 AIPose。该方法仅使用 IMU 数据作为输入，通过 IMU 特征提取模块、姿态重构模块和 IMU 预测模块构建闭环建模框架，在恢复当前时刻人体姿态的同时，对未来 IMU 信号及未来姿态进行递归预测。实验结果表明，在二维关键点坐标空间中，AIPose 在 XRFV2 数据集上的当前姿态重构平均关节位置误差为 50.56，未来姿态预测平均关节位置误差为 56.29。相关结果说明，所提出方法在当前姿态重构以及未来短时预测任务上具有较好的有效性。

最后，从整体研究内容来看，本文分别从多模态特征对齐与融合、跨受试者少样本适配以及人体运动时序建模三个方面，对基于非视觉传感器的人体行为感知问题进行了研究。相关结果表明，基于 IMU 和 WiFi 的多模态方法能够较好支持室内环境下的人体活动识别，而基于 IMU 的自回归建模方法也为人体姿态的重构与短时预测提供了可行思路。

\xsection{展望}{Future Work}

尽管本文取得了一定研究结果，但仍有一些问题值得进一步研究。

首先，本文提出的活动识别方法在受试者内测试中表现较好，但在跨受试者场景下仍然存在明显性能下降，说明模型对个体差异和环境变化仍较为敏感。后续可以进一步研究更加稳定的跨域表征学习方法，例如结合自监督预训练、域泛化或无监督适配策略，减少模型对目标受试者标注数据的依赖，并提升模型在新受试者和新场景下的直接泛化能力。

其次，本文的人体姿态任务已经能够实现较好的当前重构和短时预测，但随着预测时间增长，误差仍会逐步累积。后续可以从两个方面继续完善：一方面，可以引入更强的时序约束与人体结构约束，提升长时间预测的稳定性；另一方面，可以探索更加合理的姿态表示方式和监督形式，以增强模型对复杂运动过程的表达能力。

最后，本文两个任务分别侧重多模态活动识别和基于 IMU 的姿态建模，尚未在统一框架下实现更深层的联合建模。后续可以探索将活动语义信息与姿态变化过程进行协同建模，进一步挖掘不同任务之间的互补关系。同时，在实际部署层面，还需要结合传感器数量、佩戴方式、系统实时性和长期使用稳定性开展更系统的评估，以提高方法在智慧康养、人机交互和居家监测等场景中的应用可行性。
