\xchapter{绪论}{Introductions}

\xsection{选题意义与应用背景}{Backgrounds}

随着人工智能（Artificial Intelligence, AI）与物联网（Internet of Things, IoT）技术的深度融合，人类社会正加速步入“万物互联、智能感知”的新时代。特别是在全球人口老龄化加剧与居民健康意识觉醒的宏观背景下，如何通过普适计算技术实现对人体全天候、非侵入式的健康监测与行为分析，已成为学术界与工业界共同关注的战略高地。从智慧养老中的跌倒检测，到智能家居中的意图理解，再到元宇宙（Metaverse）中的虚实交互，人体活动识别（Human Activity Recognition, HAR）与人体姿态重构（Human Pose Reconstruction）作为连接物理世界与数字世界的关键纽带，其研究价值日益凸显。

然而，现有的单一感知手段在面对复杂多变的实际应用场景时，仍存在难以突破的瓶颈。基于计算机视觉（Computer Vision）的方案虽然在理想环境下精度较高，但在光照剧烈变化、物体遮挡（如家具遮挡、被子覆盖）等非受控场景中鲁棒性急剧下降；更为关键的是，摄像头采集的图像数据包含大量面部及环境隐私信息，给用户带来了极大的心理负担，严重限制了其在家庭等私密空间的普及。另一方面，单一的惯性测量单元（IMU）虽然具备佩戴便携、不受视场角限制的优势，但受限于微机电系统（MEMS）的工艺特性，其测量数据存在累积误差与漂移问题，难以长时间维持全局位置的精确估计；而单一的Wi-Fi感知技术虽实现了无接触式检测，却对环境变化极为敏感，易受多径效应干扰，且难以捕捉肢体末端的细微动作。因此，探索一种融合多种传感模态、兼顾低成本与高精度、且具备隐私保护特性的智能化解决方案，已成为当前人体感知领域亟待解决的关键科学问题。

本研究聚焦于基于IMU与Wi-Fi多模态融合的人体活动识别与姿态重构技术。这两类传感器在当前的智能生态中已具备极高的普及率——IMU广泛内置于智能手表、手环及耳机中，而Wi-Fi信号则充斥于现代室内环境。二者在物理感知特性上呈现出天然的互补性：IMU擅长捕捉人体局部的精细加速度与角速度变化，能够反映动作的内部动力学特征；而Wi-Fi信号（特别是信道状态信息CSI）则能通过信号的反射与散射，感知人体在宏观空间中的位移轨迹与环境扰动。通过深度挖掘并融合这两类模态的时空特征，不仅能够有效克服单一传感器在遮挡、漂移等方面的局限性，还能显著提升系统在跨场景、跨用户条件下的鲁棒性与泛化能力。

在人体活动识别任务中，本研究提出的多任务协同识别方法具有重要的理论意义与应用价值。传统的识别系统往往局限于单一的动作分类，忽略了“谁（Identity）”在“哪里（Scene）”做“什么（Activity）”的完整语义关联。本文通过引入对比学习机制，将异构的IMU与Wi-Fi特征映射至同一语义空间进行对齐，实现了活动识别、身份识别与场景识别的同步进行。这种全方位的感知能力对于构建个性化的主动健康服务至关重要。例如，在多成员的智慧家庭场景中，系统不仅能精准识别是“老人”还是“儿童”发生了“跌倒”或“长时间静坐”，还能结合“浴室”或“客厅”的场景信息，综合研判风险等级，从而触发更精准的急救响应机制；在智能安防领域，该技术可在完全不侵犯肖像隐私的前提下，实现对特定人员行为轨迹的连续追踪与异常行为预警。

在人体姿态重构任务中，本研究提出的自回归式重构与预测方法为连续动作捕捉与人机交互提供了新的范式。现有的姿态估计方法多关注当前时刻的静态重建，缺乏对时序动作演变的动态建模与预测能力。本文利用IMU数据的自回归特性，不仅实现了厘米级精度的全身姿态重构，还具备了对未来动作趋势的预测能力。这一技术突破在虚拟现实（VR/AR）与康复医疗中意义重大：在元宇宙交互中，姿态预测可以有效补偿网络传输带来的延迟，消除视觉与前庭系统的冲突，提供更流畅、无眩晕感的沉浸式体验；在远程医疗与康复训练中，系统可实时监测患者的运动轨迹，并基于预测模型提前识别可能的危险动作（如康复过程中的代偿性错误动作），及时发出语音或震动预警，从而降低二次受伤的风险，辅助医生制定更科学的诊疗方案。

综上所述，本研究成果不仅在多模态数据融合、跨域特征对齐及自回归生成模型等理论层面具有学术创新性，更在智慧医疗、智能家居、安防监控及数字孪生等实际应用领域展现出广阔的社会效益与产业前景。

\xsection{国内外研究现状分析}{Backgrounds}

人体活动识别（Human Activity Recognition, HAR）与人体姿态重构（Human Pose Reconstruction, HPR）作为连接物理世界人类行为与数字孪生空间信息交互的关键纽带，是普适计算、计算机视觉、物联网及人工智能交叉领域的研究热点。随着深度学习技术的突飞猛进以及传感硬件工艺的微型化与低功耗化，该领域的研究范式正经历着从单一模态向多模态协同感知、从离散动作分类向连续姿态建模与预测的深刻变革。

\xsubsection{人体活动识别方法研究现状}{Level of this document}

人体活动识别旨在利用传感器数据感知并理解人类的行为模式。根据数据采集模态的不同，现有的主流研究方法可系统地划分为基于计算机视觉的方法、基于无线射频信号的方法以及基于可穿戴传感器的方法。此外，多模态融合技术因其能互补不同传感器的优劣势，正逐渐成为提升系统鲁棒性的关键路径。

\subsubsection{基于计算机视觉的活动识别}
基于视觉的活动识别是目前发展最为成熟、精度最高的技术流派，主要依赖RGB摄像头、深度相机（RGB-D）等设备采集视频流数据。其技术演进脉络大致可分为基于手工特征的传统方法和基于深度学习的端到端方法。

1）基于手工特征的传统方法：早期的研究侧重于设计能够描述人体运动的时空特征算子。经典的“时空兴趣点”（Space-Time Interest Points, STIP）方法将2D图像中的角点检测扩展至3D时空维度，提取显著的运动变化区域；“光流直方图”（Histogram of Optical Flow, HOF）和“运动边界直方图”（MBH）则通过捕捉像素点的瞬时速度场来描述动作模式。这些特征通常结合词袋模型（Bag of Words, BoW）进行编码，并利用支持向量机（SVM）或隐马尔可夫模型（HMM）进行分类。虽然这些方法奠定了HAR的理论基础，但其特征设计高度依赖专家经验，且难以捕捉长时序的复杂语义关联。

2）基于深度学习的方法：随着卷积神经网络（CNN）的兴起，视觉HAR迎来了爆发式增长。其中，“双流网络”（Two-Stream Networks）架构具有里程碑意义，它通过空间流处理RGB帧提取表观特征，通过时间流处理光流场提取运动特征，最后融合两路输出，显著提升了识别性能。随后，C3D、I3D（Inflated 3D ConvNets）以及SlowFast等3D卷积网络架构被提出，它们直接在视频的时空维度上进行卷积操作，能够端到端地学习分层的运动特征。此外，针对人体骨骼数据，基于图卷积网络（Graph Convolutional Networks, GCN）的方法（如ST-GCN）将人体关节建模为图节点，骨骼建模为边，能够有效捕捉人体拓扑结构中的空间依赖性，在动作识别中展现出极高的效率。

尽管视觉感知在理想的受控环境下已能达到极高的识别精度，但在实际的非受控场景部署中仍面临难以逾越的屏障：
\begin{itemize}
    \item 鲁棒性瓶颈：视觉算法对环境因素极度敏感。光照剧烈变化（如夜间或逆光）、背景动态杂波以及物体遮挡（如家具遮挡下半身、被子覆盖全身）都会导致特征提取失效，识别性能急剧下降。
    \item 隐私与算力约束：摄像头采集的图像包含大量用户面部、衣着及生活环境等敏感隐私信息，这在家庭、医院等私密空间引发了严重的伦理与安全担忧。同时，处理高帧率视频流对计算资源（GPU）和存储带宽要求极高，难以在资源受限的边缘端设备上长时间运行。
\end{itemize}

\subsubsection{基于环境射频信号的活动识别}
为了克服视觉感知的隐私侵犯与光照依赖问题，基于Wi-Fi、毫米波雷达、RFID等射频信号的非接触式感知技术（Device-free Sensing）应运而生。其中，Wi-Fi感知因其基础设施广泛普及、零额外部署成本的优势而备受关注。

早期的Wi-Fi感知主要利用接收信号强度（RSSI）指纹，但RSSI属于媒体访问控制（MAC）层的粗粒度特征，易受多径叠加导致的信号波动影响，稳定性较差。近年来，研究重心已全面转向物理层（PHY）的信道状态信息（Channel State Information, CSI）。CSI 描述了无线信号在发射端与接收端之间每一条子载波上的幅度和相位响应。当人体在Wi-Fi覆盖区域内活动时，会对信号传播路径产生反射、散射与衍射，导致CSI呈现出特定的波动模式。通过分析这种多径效应引起的微多普勒特征（Micro-Doppler Effect），研究人员可以推断人体的呼吸频率、步态特征甚至手势动作。例如，Wi-Vi系统利用天线阵列消除静态反射，追踪墙后人体移动；Wi-mesh等前沿工作则尝试利用深度神经网络从CSI幅值波动中重构人体3D网格。

尽管Wi-Fi感知具有非接触、覆盖广、保护隐私的天然优势，但其核心痛点在于跨域泛化能力（Cross-Domain Generalization）极弱。无线信号对环境变化极度敏感，不同的房间布局、家具摆放位置、收发设备的朝向甚至空气湿度都会显著改变信号传输的信道模型（Channel Model）。在一个场景下训练良好的模型，往往难以直接迁移到另一个新场景中，这极大地限制了其大规模商用落地。此外，受限于Wi-Fi信号的波长与带宽，单一Wi-Fi模态的空间分辨率有限，难以捕捉人体肢体末端的细微动作（如手指颤动），限制了其在精细化康复评估等领域的应用深度。

\subsubsection{基于可穿戴传感器的活动识别}
惯性测量单元（Inertial Measurement Unit, IMU）通常集成三轴加速度计、三轴陀螺仪和三轴磁力计，凭借其低成本、低功耗、体积小巧及不受视场角限制的特性，已成为可穿戴识别的主流方案。

与视觉和射频信号不同，IMU直接测量的是人体局部的运动学参数（加速度、角速度）。现有的研究多将IMU传感器数据视为多维时间序列，利用滑动窗口技术进行切片，并输入到长短时记忆网络（LSTM）、门控循环单元（GRU）、一维卷积神经网络（1D-CNN）或Transformer架构中进行特征学习。近年来，DeepSense、TransPose等工作证明了IMU在捕捉局部肢体高频动态及克服遮挡问题方面的独特优势。特别是随着智能手表、手环、无线耳机的普及，基于单点或稀疏IMU的HAR技术已具备了广泛的用户基础。

然而，单一IMU模态存在先天的物理局限性：
\begin{itemize}
    \item 缺乏全局环境上下文：IMU只能感知自身的运动状态，无法直接感知用户所处的环境信息（如“在厨房”还是“在卧室”）以及与周围物体的交互关系，这导致难以区分具有相似运动模式但语义完全不同的活动（例如“在厨房切菜”与“在书房写字”的动作信号极为相似）。
    \item 积分漂移问题：受限于MEMS工艺，低成本IMU存在固有的零偏（Bias）和噪声。在进行长时间位移积分时，误差会随时间二次方累积，导致全局位置估计迅速发散，难以维持高精度的轨迹追踪。
\end{itemize}

\subsubsection{多模态融合与多任务协同的局限性}
为了突破单一模态的感知瓶颈，实现优势互补，学术界开始探索多模态融合技术（如Vision+IMU, Wi-Fi+IMU）。然而，现有的融合方法多停留在数据层或特征层的简单拼接（Concatenation）或加权平均，忽略了异构数据在物理属性、采样频率及语义层次上的巨大差异。例如，IMU数据反映的是本体坐标系下的局部动力学特征，而Wi-Fi CSI反映的是世界坐标系下的全局空间扰动特征，两者存在严重的“模态鸿沟”（Modality Gap），直接拼接往往导致模型无法有效对齐两种特征，甚至引入噪声干扰。

此外，绝大多数现有工作仅关注单一的“活动分类”任务，人为割裂了“身份识别（Identity）”与“场景感知（Scene）”之间的内在逻辑关联。实际上，在真实的家庭或医疗监控场景中，活动、身份与场景在语义上是高度耦合的（例如，“老人在浴室跌倒”与“青年在客厅运动”具有完全不同的风险等级和响应需求）。缺乏多任务协同机制使得现有系统难以构建全方位的用户画像，无法满足复杂场景下的智能化与个性化服务需求。

针对上述不足，本课题提出了一种基于对比学习（Contrastive Learning）的多模态融合框架，通过设计特定的损失函数将异构的IMU与Wi-Fi特征映射至统一的语义空间进行显式对齐，并设计了多任务分类器，旨在实现活动、身份与场景的同步高精度识别。

\xsubsection{人体姿态重构方法研究现状}{Level of this document}

人体姿态重构（Human Pose Reconstruction, HPR）旨在从传感器数据中恢复人体的三维骨架或参数化网格模型（如SMPL模型），不仅关注动作的类别，更致力于数字化复现人体的几何形态与运动细节。

\subsubsection{基于视觉的三维姿态重构}
基于视觉的重构方法主要利用大规模2D/3D人体数据集（如Human3.6M, AMASS），通过深度神经网络直接从RGB图像回归SMPL模型的参数（姿态角$\theta$与形状参数$\beta$）。代表性工作包括HMR（Human Mesh Recovery）、SPIN（SMPL oPtimization IN the loop）、VIBE（Video Inference for Body Pose and Shape Estimation）等。这些方法引入了对抗生成网络（GAN）或时序注意力机制，在理想光照条件下能够实现极高精度的重建，甚至能恢复衣服褶皱等细节。

然而，视觉方法在实际应用中面临两个本质难题：
\begin{itemize}
    \item 深度歧义性（Depth Ambiguity）：从2D图像平面反推3D空间结构本身是一个病态问题（Ill-posed Problem），单一视角下难以准确恢复人体的绝对深度和尺度信息。
    \item 遮挡脆弱性：在存在严重遮挡（如被子覆盖、桌椅遮挡）或光线昏暗的非受控场景中，关键点检测网络容易失效，导致姿态估计出现严重的扭曲或伪影，无法满足全天候监测的需求。
\end{itemize}

\subsubsection{基于稀疏惯性传感器的姿态重构}
为了解决视觉方法的遮挡与隐私问题，基于稀疏IMU（通常佩戴于手腕、脚踝、头部及骨盆等6个节点）的姿态重构近年来成为研究热点。该技术路线主要分为基于优化的方法和基于数据驱动的方法。

1）基于优化的方法：早期的工作主要基于多体动力学模型，通过融合加速度计和陀螺仪数据，利用卡尔曼滤波（EKF）或互补滤波来解算关节角度。同时，利用人体运动学链的约束（如骨骼长度不变、关节旋转范围限制）构建能量函数，通过最小化能量来求解姿态。这类方法具有明确的物理可解释性，但求解过程涉及复杂的非线性优化，计算复杂度高，容易陷入局部最优解，难以满足实时性交互的需求。

2）基于数据驱动的方法：随着AMASS等大规模动捕数据集的发布，基于深度学习的方法逐渐占据主导。该类方法利用双向RNN（BiRNN）、Transformer或图神经网络，直接学习从稀疏IMU序列到全身SMPL姿态参数的映射关系。例如，DIP（Deep Inertial Poser）利用RNN从6个IMU数据回归全身姿态；TransPose利用多阶段Transformer网络分别估计关节位置和旋转；PIP（Physical Inertial Poser）则引入物理模拟器作为监督信号，减少非自然姿态的生成。

尽管取得了显著进展，但现有的IMU重构方法仍面临两大核心瓶颈：
\begin{enumerate}
    \item 缺乏预测能力与网络延迟补偿：现有的主流模型（如TransPose）多为判别式模型，侧重于利用当前或过去的数据窗口重建当前时刻的姿态（Reconstruction），缺乏对未来动作趋势的推演与预测能力（Prediction）。在元宇宙交互、远程医疗手术或云游戏等实际应用中，网络传输延迟是不可避免的物理法则。缺乏预测能力会导致终端呈现的动作滞后于用户的实际动作，产生“视觉-前庭冲突”，严重影响用户的沉浸式体验甚至导致晕动症。
    \item 误差累积与动作抖动：IMU传感器的高频噪声以及人体运动的复杂性，使得单纯依赖回归模型容易导致重构出的动作在静止时产生非自然的微小抖动（Jitter），或在快速运动时产生较大的位置偏差。现有的平滑算法（如低通滤波）虽然能减轻抖动，但往往以牺牲动作的灵敏度和实时性为代价。
\end{enumerate}

\subsubsection{自回归生成式方法的缺位}
在自然语言处理（NLP）领域，以GPT为代表的自回归（Autoregressive）模型展现了强大的序列生成与预测能力，能够根据上文信息精准预测下一个Token。在计算机视觉领域，基于扩散模型（Diffusion Model）的动作生成也初露锋芒。然而，在人体姿态重构领域，特别是基于稀疏IMU数据的重构任务中，通过自回归机制同时实现高精度姿态重构与未来动作预测的研究仍处于起步阶段。

自回归生成模型能够显式地建模动作序列的联合概率分布，学习人体运动内在的时序演变规律（Temporal Dynamics）。这种机制不仅能利用历史信息平滑当前的姿态估计，有效抑制噪声抖动，更关键的是，它天然具备生成未来序列的能力，能够在数据丢失或网络延迟时，基于历史状态精准预测未来的姿态，实现“零延迟”甚至“负延迟”的交互体验。

基于此，本课题提出了一种创新的基于自回归的人体姿态重构与预测方法。不同于现有的判别式映射网络，本方法设计了包含姿态重构器与IMU预测器的闭环结构，利用IMU数据的自回归特性，实现了厘米级精度的姿态重构，并赋予了系统对未来动作的预测能力，有效克服了传统方法在实时性、抗干扰性及延迟补偿方面的不足。
