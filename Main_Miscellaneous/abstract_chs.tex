\begin{chineseabstract}

随着智能穿戴设备和人工智能技术的发展，利用非视觉传感器实现人体运动状态建模逐渐成为研究热点。其中，惯性测量单元（Inertial Measurement Unit, IMU）能够高频采集人体运动的动力学信息，而 WiFi 信号中的信道状态信息（Channel State Information, CSI）能够反映人体运动对无线传播环境产生的扰动。与视觉传感器相比，该类感知方式具有隐私友好、部署灵活以及环境适应性较强等特点。然而，在实际应用中仍面临若干问题：不同模态传感数据在信号形式与特征分布上存在明显差异，导致多模态信息难以有效对齐和融合；不同受试者之间的运动习惯与身体特征差异会导致模型在跨受试者场景下性能下降；现有的人体姿态重构方法多集中于当前姿态重构，缺乏对未来时刻姿态的建模能力。

针对上述问题，本文围绕人体活动识别与人体姿态重构两个任务展开研究。在人体活动识别任务中，针对 IMU 与 WiFi CSI 数据之间的异构特征难以有效融合，以及跨受试者泛化能力不足的问题，提出一种基于多模态对齐与融合的人体活动识别方法 WIHAR。该方法通过跨模态对比学习\cite{radford2021learning}策略，将 IMU 的运动动力学特征与 WiFi CSI 的射频感知特征映射到统一语义空间，并利用交叉注意力机制实现两种模态之间的特征交互。在此基础上，通过基于类别原型的特征对齐策略，将目标域特征映射至源域语义结构中，从而有效缓解跨受试者分布不一致问题。实验结果表明，在 XRFV2 数据集\cite{lan2025xrf}上，WIHAR 在人体活动识别任务中取得 96.06\% 的活动识别准确率；在跨受试者实验中，模型平均活动识别准确率为 72.57\%，经少量目标受试者数据微调后可提升至 90.99\%。
    
在人体姿态重构任务中，针对现有方法缺乏时序预测能力的问题，提出一种基于自回归建模机制的人体姿态重构与预测方法 AIPose。该方法使用 IMU 数据作为输入，通过构建由 IMU 特征提取模块、姿态重构模块和 IMU 预测模块组成的闭环结构，利用当前 IMU 序列预测未来 IMU 序列，并进一步用于未来时刻姿态预测，从而在实现当前姿态重构的同时实现未来时刻姿态预测。实验结果表明，AIPose 在 XRFV2 数据集上的当前姿态重构平均关节位置误差为 50.56，未来时刻姿态预测平均关节位置误差为 56.29。

\end{chineseabstract}
