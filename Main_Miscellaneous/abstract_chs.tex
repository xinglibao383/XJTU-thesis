\begin{chineseabstract}

    随着智能穿戴设备与人工智能技术的快速发展，基于非视觉传感器的人体运动状态建模逐渐成为研究热点。相较于传统视觉感知，非视觉传感具有隐私友好、部署灵活以及环境适应能力强等优势。其中，惯性测量单元（Inertial Measurement Unit, IMU）能够高频采集人体运动的动力学信息，而 WiFi 信号中的信道状态信息（Channel State Information, CSI）能够反映人体运动对无线传播环境的扰动。然而，该类方法在实际应用中仍面临若干挑战：不同传感模态在信号形式与特征分布上存在显著差异，导致多模态特征难以有效对齐与融合；不同受试者之间的运动习惯与身体特征差异，使模型在跨受试者场景下的泛化能力受限；此外，现有人体姿态重构方法多聚焦于当前姿态重构，而缺乏对未来姿态的预测能力。针对上述问题，本文围绕人体活动识别与人体姿态重构两个关键任务展开研究。

    在人体活动识别任务中，针对 IMU 与 WiFi CSI 数据异构性强以及跨受试者泛化能力不足的问题，本文提出一种基于多模态对齐与融合的人体活动识别方法 WIHAR。该方法通过引入跨模态对比学习策略\cite{radford2021learning}，将 IMU 的运动动力学特征与 WiFi CSI 的射频感知特征映射至统一的语义空间，并结合交叉注意力机制实现模态间的深度特征交互，从而提升特征表达能力。实验结果表明，在 XRFV2 数据集上，WIHAR 的人体活动识别准确率可达 96.06\%。在此基础上，本文进一步设计了一种基于类别原型的特征对齐策略，通过缩小目标域特征与源域类别原型之间的差距，缓解跨受试者泛化能力不足的问题。实验结果表明，通过少量目标受试者数据微调，模型的平均准确率可以由 72.57\% 提升至 90.99\%。
    
    在人体姿态重构任务中，针对现有方法缺乏未来姿态预测能力的问题，本文提出基于自回归建模的人体姿态重构与预测方法 AIPose。该方法通过构建由 IMU 特征提取模块、姿态重构模块和 IMU 预测模块组成的闭环结构，输入 IMU 序列，以自回归的形式预测未来 IMU 序列，并作为中间表示进一步进行未来姿态预测。实验结果表明，AIPose 在 XRFV2 数据集上的当前姿态重构平均关节位置误差（Mean Per Joint Position Error, MPJPE）为 47.82，未来姿态预测为 54.11。
